# Pedido de corrección para el agente desde un hallazgo

- ESTADO: ABIERTA
- PRIORIDAD: 15
- ETIQUETAS: revision, autoproduccion


## Objetivo

Un comando que arme el pedido de corrección de un hallazgo para el agente: ubicación, evidencia, requisito relacionado y la regla de traer una prueba que falle en el código viejo (lo que hoy el agente hace a mano en cada vuelta). Es el «fix with agent» del video, con el hallazgo fundamentado como entrada.

Origen: video «AI Coding Agents + Static Code Analysis for Safer Code» (IBM Developer, 2026-10-08), que Brian pidió aplicar a Factory.
