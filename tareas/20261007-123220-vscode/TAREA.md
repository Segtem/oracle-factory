# Extensión fina de VS Code para revisar un cambio de Factory

- ESTADO: ABIERTA
- PRIORIDAD: 14
- ETIQUETAS: revision, ide


## Objetivo

Árbol cambio → requisitos → medidas y veredicto → archivos y líneas; CodeLens «respalda: <requisito>» sobre el código; marca en el margen para líneas sin respaldo; abrir el informe y las decisiones de la revisión guiada. Lee la CLI en JSON (o factory-mcp). Los botones de decisión abren el comando en la terminal integrada para que la persona escriba la frase: la extensión muestra y guía, no decide.

Parte del plan de revisión en el IDE (tarea 20261005-112955-revision-ide, Brian 2026-10-07): unir requisitos, medidas, veredicto y código para que una persona revise el código hecho por IA por promesa, no por archivo. Las decisiones siguen siendo humanas y pasan por la terminal.
