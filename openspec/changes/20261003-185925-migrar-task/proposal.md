# Migrar el tracker a Oracle Task

Pedido humano: «actualizar todos los repos que usen trackertask a oracle-task y luego eliminarlo de pypi».
Esta propuesta concreta ese pedido: sustituir la dependencia y la resolución del comando tasks,
conservar las tareas existentes y actualizar las instrucciones. Preparar 0.1.0a2 para PyPI.
La autorización es el pedido de esta conversación; no se simulan aprobaciones de la CLI.
